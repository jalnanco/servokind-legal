Privacy Policy — Servokind Uploader

Last updated: 2026-09-28

Data we access

When the channel owner authorizes the tool, TikTok returns an access token, a refresh token, and basic profile information (open ID and display name) for the channel's own account. The tool uploads only video files that Servokind produced itself.

How it is stored

Tokens are stored only on the owner's computer, in the operating system's encrypted keychain. Nothing is sent to any server other than TikTok's API.

Sharing

No data is sold, shared with third parties, or used for advertising or analytics.

Deletion

Revoking the app in TikTok settings (Security → Manage app permissions) invalidates the tokens; the local copies are then deleted.

Instagram (Meta app “servokind-stats”)

The same owner uses a Meta app, servokind-stats, only with Servokind's own Instagram professional accounts (@servokind.kr, @servokind.jp, @servokind). With the owner's authorization it reads those accounts' own posts and insights, reads the comments that viewers leave on those posts (comment text, username, time), and posts the owner's replies to them. It does not access any other account.

Comment data is kept only on the owner's computer so the owner can read and answer it. It is not sold, shared, or used for advertising. Access tokens are stored in the operating system's encrypted keychain.

To remove the app's access or ask for deletion of any comment data, see Data deletion.
